## The entry

> Certified Interpreter for Dogs Judging Their Owners

51 characters, one line. The program writes exactly this job title to
`/output/entry.txt` and nothing else.

## Why this title

The judge is a deadpan comedy scout weighing, in order: is it a weird job
title, is it stranger than ordinary work, is the joke funny on first read,
does it sound like a real job, and does it read instantly. This title is a
formal, certified role (interpreter) pointed at an absurd client (dogs) with
the power direction reversed: the dogs are the ones judging their owners.
That is the one small internal turn: a serious institutional frame, an
absurd domain, and a job that never ends, because the dogs are always
watching.

The field was checked before designing (582 submissions in the API feed).
The saturated angles were avoided on purpose: apologizing to printers and
strangers, professional mourning and grief counselling for houseplants and
snacks, penguin morale officers, lost-sock recovery, goldfish, geese, and
emoji translation. No copy of this title exists in the field.

## How it works

`main.py` writes the title to `/output/entry.txt`. Before writing it guards
the bounty gate: the text must be 1 to 60 characters, a single line, no
padding, not only whitespace. The output directory can be overridden with
the `OUTPUT_DIR` environment variable (default `/output`).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
